## What changed vs previous versions

This is the first dedicated feature doc for public Fault conversion at the v2.0 documentation baseline.

Breaking / notable changes vs v1.3.x:

- `NewPublicFaultFromAnyError` now takes a variadic `options ...ConversionOption` instead of the old fixed signature / `NO_LOG_LABELS` approach.
- `NO_LOG_LABELS` was removed.
- `ConversionOption` is a public interface (renamed from unexported `conversionOption` in 2.0.1) so other libraries can wrap conversion.
- Supported option factories:
  - `OptionLogLabels(labels []kt_logging.Label)`
  - `OptionWhitelistedFaultKinds(inheritErrorCodes bool, kinds ...FaultKind)`

Within 2.0.x (release 2.0.4):

- `inheritErrorCodes=true` on a plain non-Fault `error` no longer panics; codes are inherited only when the original is a `Fault`.
- Nil entries in the `options ...ConversionOption` list are skipped safely.

## TLDR

- Use `NewPublicFaultFromAnyError` at a public boundary (HTTP/gRPC handler, message consumer, etc.) to turn any `error` into a **public** `Fault`.
- Already-public Faults pass through unchanged.
- Everything else is treated as unsafe: original is logged, a safe public Fault is built (generic message + usually `ERRCODE_INTERNAL_ERROR`), original becomes `cause`.
- Fine-tune with `ConversionOption`s (extra log labels; whitelist kinds / optionally inherit error codes).

## When to use

Call this once when an error is about to leave your private boundary and might be returned to a client or another trust domain.

Do **not** use it deep inside business logic just to “normalize” errors — keep rich non-public Faults while bubbling up (see [Fault-v2.0.md](Fault-v2.0.md)), then convert at the edge.

## API

```go
func NewPublicFaultFromAnyError(
    original error,
    transactionId string,
    loggerToUse *kt_logging.Logger,
    options ...ConversionOption,
) Fault
```

Parameters:

- `original` — error to convert; `nil` returns `nil`
- `transactionId` — optional correlation id:
  - added as Fault label `"transactionId"` when used in the default message path
  - may appear in the default public message template
  - also forced onto the log event (as `trId`) if not already present in option log labels
- `loggerToUse` — logger for the warn event that captures the unsafe original; if `nil`, package default logger (`kt_logging.GetLogger(PACKAGE_NAME)`) is used
- `options` — zero or more `ConversionOption` values (nil entries in the slice are ignored)

## Behavior overview

1. If `original` is `nil` → return `nil`.
2. If `original` is already a public `Fault` → return it as-is (no logging, no rebuild).
3. Otherwise treat as unsafe and convert.

### Unsafe conversion (non-Fault or non-public Fault)

Always:

- Log a warn with the original error (via `VarPrinter` for Faults / original for plain errors).
- Build a **public** Fault with `NewPublicFaultBuilder`.
- Attach `original` as `cause`.
- Default kind is `RuntimeFault`.
- Default message:
  - with `transactionId`: `"Error occured during processing, details are logged with transactionId '{transactionId}'"` + label `transactionId`
  - without: `"Error occured during processing, details are logged"`
- Unless the original kind was kept via whitelist (below), add `ERRCODE_INTERNAL_ERROR`.

### Extra rules when original is a non-public Fault

- `IsRetryable()` is inherited.
- If a message template for audience `MSGAUDIENCE_USER` exists:
  - it becomes the main public message template
  - that audience entry is removed from the inherited audience map
- Remaining audience message templates are copied to the new Fault.
- Labels are **not** copied wholesale. Only labels whose keys appear as `{var}` placeholders in the (user / remaining audience) templates are kept.
- Original error codes are **not** copied by default (they may leak internals). Use `OptionWhitelistedFaultKinds(..., inheritErrorCodes=true)` to opt in when the kind is whitelisted path is active — see below.

## Conversion options

`ConversionOption` is a public interface. Construct options only via the `OptionXXX` helpers unless you intentionally implement wrappers in another library.

### `OptionLogLabels`

```go
kt_errors.OptionLogLabels([]kt_logging.Label{ ... })
```

- Extra labels decorate the warn log event for the unsafe original.
- You do not need this only for `transactionId`: that id is still forced onto the log when provided as the `transactionId` argument.

### `OptionWhitelistedFaultKinds`

```go
kt_errors.OptionWhitelistedFaultKinds(inheritErrorCodes bool, kinds ...FaultKind)
```

When converting a non-public Fault whose kind is in `kinds`:

- The public Fault **keeps that kind** instead of forcing `RuntimeFault`.
- `ERRCODE_INTERNAL_ERROR` is **not** added (whitelist implies a deliberate special case).

Independently of whether the kind was kept:

- If `inheritErrorCodes` is `true` **and** the original is a `Fault`, original error codes are copied onto the public Fault.
- If the original is a plain non-Fault `error`, `inheritErrorCodes` has no effect (no panic).
- If the kind was not whitelisted, the Fault still becomes `RuntimeFault` and still gets `ERRCODE_INTERNAL_ERROR`, plus any inherited codes when that flag is on and the original was a Fault.

Typical use: allow selected client-meaningful kinds (e.g. `ValidationFault`, `AuthenticationFault`) to survive the boundary while still scrubbing unsafe default messages / labels.

## Example

```go
publicFault := kt_errors.NewPublicFaultFromAnyError(
    err,
    transactionId,
    logger,
    kt_errors.OptionLogLabels([]kt_logging.Label{
        kt_logging.StringLabel("component", "api"),
    }),
    kt_errors.OptionWhitelistedFaultKinds(
        false,
        kt_errors.ValidationFault,
        kt_errors.AuthenticationFault,
        kt_errors.AuthorizationFault,
        kt_errors.ResourceNotFoundFault,
    ),
)
```

## Design notes

- Conversion is the safety gate: non-public Faults may mention internal systems, configs, stacks, etc.
- Logging the original before scrubbing is mandatory for operability — the public Fault intentionally drops detail.
- Prefer putting a clear `MSGAUDIENCE_USER` message on non-public Faults when you already know a safe user-facing sentence; conversion will promote it.
